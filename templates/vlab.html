The Bias-Variance Tradeoff: At Degree 1, the model suffers from High Bias (Underfitting), unable to capture the sinusoidal curvature. As degree increases to 3–4, both train and test error reach a minimal equilibrium. Above Degree 6 without regularization, the model exhibits High Variance (Overfitting) — memorizing sample noise and oscillating between points, causing test error to explode.

import numpy as np
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import Ridge

# Generate synthetic dataset: y = sin(2*pi*x) + noise
np.random.seed(42)
X_train = np.sort(np.random.rand(15, 1), axis=0)
y_train = np.sin(2 * np.pi * X_train).ravel() + np.random.normal(0, 0.2, 15)

# Fit polynomial regression with L2 regularization
degree = 3
alpha = 0.001
model = make_pipeline(PolynomialFeatures(degree), Ridge(alpha=alpha))
model.fit(X_train, y_train)

# Predict on dense evaluation grid
X_eval = np.linspace(0, 1, 200).reshape(-1, 1)
y_pred = model.predict(X_eval)

Learning Rate Sensitivity: If α is too small, convergence requires hundreds of steps and may become trapped in local shallow basins. If α exceeds the Lipschitz threshold (> 0.9), gradients overshoot the minimum, causing catastrophic loss explosion / divergence. Notice how the update rule x ← x - α ∇f(x) steps downhill along the steepest tangent slope.

def loss_func(x):
    return x**4 - 3*x**2 + 0.5*x

def grad_func(x):
    return 4*x**3 - 6*x + 0.5

# Gradient Descent Loop
x = -2.4  # Initial position
alpha = 0.15  # Learning rate
history = [x]

for step in range(25):
    gradient = grad_func(x)
    x = x - alpha * gradient
    history.append(x)
    if abs(gradient) < 1e-4:
        print(f"Converged at step {step}: x={x:.4f}, loss={loss_func(x):.4f}")
        break

Expectation-Maximization in K-Means: The algorithm alternates between two steps: (1) Assignment Step: each data point is assigned to its closest centroid in Euclidean space. (2) Update Step: each centroid is recomputed as the arithmetic mean of all points assigned to it. Inertia drops monotonically on every step until the centroids stabilize.

from sklearn.cluster import KMeans
from sklearn.datasets import make_blobs

# Generate 2D Gaussian clusters
X, y_true = make_blobs(n_samples=80, centers=3, cluster_std=0.8, random_state=42)

# Fit K-Means
kmeans = KMeans(n_clusters=3, random_state=42, n_init=10)
labels = kmeans.fit_predict(X)
centroids = kmeans.cluster_centers_
inertia = kmeans.inertia_

print(f"Final WCSS Inertia: {inertia:.2f}")
print("Centroid coordinates:\n", centroids)

Linear vs Kernel Separability: Linear models (like standard Logistic Regression or Linear SVM) can only draw straight hyperplane partitions, failing on non-linearly separable topologies like Interlocking Moons. Applying polynomial feature mappings or RBF kernels maps the inputs into higher-dimensional feature space where non-linear boundaries smoothly classify complex structures.

from sklearn.datasets import make_moons
from sklearn.svm import SVC
from sklearn.metrics import accuracy_score, f1_score

X, y = make_moons(n_samples=100, noise=0.15, random_state=42)

# Train Support Vector Classifier with RBF Kernel
clf = SVC(kernel='rbf', C=1.0, gamma='scale')
clf.fit(X, y)

preds = clf.predict(X)
print("Accuracy:", accuracy_score(y, preds))
print("F1 Score:", f1_score(y, preds))
